## 1. Executive Summary

This audit evaluates how raw examples from `train/train.jsonl` are transformed into supervised training sequences (`data/sft/sft_train.jsonl` and `data/sft/candidates/simulator_grounded_merged_v1.1/sft_train.jsonl`).

### Major Discoveries & Root Causes of Underperformance
1. **Severe Training-vs-Inference Prompt Mismatch (CONFIRMED)**:
   In [`scripts/data/generate_reasoning_sft.py`](file:///c:/Users/phuon/zalo-challenge/scripts/data/generate_reasoning_sft.py#L424-L429), `build_initial_messages()` was invoked **without passing `catalog_apps_map` and without passing `router`**:
   - In training: App headers read `[Ứng dụng: weather (weather) | Nhóm: ]` with **zero Vietnamese app names, zero category groups, and zero application descriptions**. Apps were ordered in raw dictionary order (`list(installed.keys())`).
   - In inference: `run_infer.py` passes `catalog_apps_map` and `SemanticToolRouter`. App headers read `[Ứng dụng: Danh bạ (contacts) | Nhóm: communication]\nMô tả: Quản lý danh bạ...`, and apps are re-ordered by TF-IDF similarity.
   - Result: The model was trained on an empty-header prompt distribution and tested on a rich Vietnamese metadata prompt distribution, inducing severe out-of-distribution confusion.
2. **Gradient Hijacking by Synthetic `<think>` Blocks (79.0% vs. 18.3%) (CONFIRMED)**:
   Analysis of all 5,774 assistant turns in `sft_train.jsonl` demonstrates that **79.0% of assistant target characters** (`1,883,249` characters) belong to synthetic `<think>` template strings generated by heuristic Python functions. Only **18.3%** (`437,288` characters) represent the actual `<tool_call>` actions that the competition evaluates. The model is effectively trained as a Vietnamese prose writer rather than a tool-calling policy.
3. **Harmful Hallucination Reinforcement in Defective Ground Truth (CONFIRMED)**:
   In `train_1696`, the original label called a non-existent ID (`chat_6142`), returning `done: false`. The synthetic CoT script generated a `<think>` block explicitly claiming that `chat_6142` is an *"ID thực tế"* and later rationalized that *"Tất cả các thao tác... đã được thực hiện đầy đủ"*, teaching the model to ignore tool failures and confirm task success.
4. **Complete Loss of `final_state` Supervision (CONFIRMED)**:
   Neither `prepare_sft_data.py` nor `generate_reasoning_sft.py` uses `label.final_state`. It is completely stripped during SFT conversion.

## 3. Tool Trajectory Conversion Audit

### 3.1 Causal ReAct Step-by-Step Structure
In `scripts/data/generate_reasoning_sft.py`:
- Each tool call $k$ becomes an assistant message:
  ```text
  <|im_start|>assistant
  <think>
  - Phân tích Intent & Routing: ...
  - Tra cứu Schema & Dependency: ...
  - Quyết định: Gọi tool <tool_name>.
  </think>
  <tool_call>
  {"name": "<tool_name>", "arguments": {...}}
  </tool_call><|im_end|>
  ```
- Each tool result $k$ immediately follows as a user message:
  ```text
  <|im_start|>user
  <tool_response>
  {...}
  </tool_response><|im_end|>
  ```
- **Observation Exposure**: Step $k+1$ assistant turn directly attends to `<tool_response>` from step $k$, preserving causal dependency.
- **Closing Turn**: When all tool calls are completed, a final assistant message is appended:
  - If last call was `sys.ask_missing_info`: `<think>...</think>\nVui lòng cung cấp thêm thông tin chi tiết để tôi thực hiện yêu cầu.`
  - If last call was a standard tool: `<think>...</think>\nĐã hoàn thành yêu cầu của bạn.`
  - If 0 tool calls were required: `<think>...</think>\nYêu cầu không cần thực hiện thao tác trên ứng dụng.`

## 5. Reasoning Supervision Audit

### 5.1 Character Breakdown in Assistant Target Spans
Across all 1,692 training samples in `simulator_grounded_merged_v1.1/sft_train.jsonl`:

```text
Total Assistant Turns Analyzed : 5,774
Total <think> Characters       : 1,883,249  (79.0%)
Total <tool_call> Characters   : 437,288    (18.3%)
Total Final Text Characters    : 63,389     ( 2.7%)
```

Because `AssistantOnlyDataCollator` computes cross-entropy loss over the entire assistant span, **79.0% of the training loss gradient updates model weights to predict the rigid 3-part Vietnamese heuristic templates**.

### 5.2 Heuristic Generation vs. Ground-Truth Reasoning
The `<think>` blocks are generated by python regex heuristics:
- `_find_conditional_phrase()`: matches keywords (`nếu`, `mai mà mưa`, etc.).
- `_find_negation_phrase()`: matches keywords (`à mà thôi`, `thôi khỏi`, etc.).
- `_summarize_tool_result()`: extracts scalar fields (`rain`, `balance`, `amount`, `id`).

**Risks Verified**:
1. **No Counterfactual Awareness**: Heuristic scripts cannot know *why* an action was chosen over alternatives—they merely state what was done.
2. **Hallucination Laundering**: In `train_1696`, the heuristic observed `chat_id="chat_6142"` in the label arguments and synthesized:
   `"- Tra cứu Schema & Dependency: Đã có đủ tham số hợp lệ cho tool write 'chat_ott.send_message' với ID thực tế (chat_id=chat_6142)..."`
   The script falsely stamped a fabricated ID as verified ground truth.

## 7. Sample-Level Mapping Audit (Summary of 5 Key Samples)

Full JSON traces are stored in [`reports/dataset_mapping_examples.json`](file:///c:/Users/phuon/zalo-challenge/reports/dataset_mapping_examples.json).

1. **`train_0001` (Multi-Step Conditional ReAct)**:
   - *Original*: 5 tools (`weather.get_forecast` -> `calendar.list_events` -> `calendar.update_event` -> `contacts.search` -> `sms.send`).
   - *Converted SFT*: 13 messages, 6 assistant turns, 5 `<think>` blocks.
   - *Verdict*: Structurally sound, but bloated by 1,420 `<think>` characters.
2. **`train_0002` (Conditional with Self-Cancellation)**:
   - *Original*: `"Nếu mai mưa thì hủy lịch... À mà thôi, cứ để lịch đó, chỉ cần xem giúp mai có mưa không."`
   - *Converted SFT*: 5 messages, 2 assistant turns, 1 tool call (`weather.get_forecast`).
   - *Verdict*: Correctly preserves cancellation of the mutation while keeping the read call.
3. **`train_0019` (Out-of-Scope Intent / Zero Tool Calls)**:
   - *Original*: `"giúp tôi đặt phòng khách sạn ở Đà Lạt"`. Hotel app not installed.
   - *Converted SFT*: 3 messages, 1 assistant turn: `<think>...</think>\nYêu cầu không cần thực hiện thao tác trên ứng dụng.`
   - *Verdict*: Correctly teaches the model to emit zero tool calls when tools are unavailable.
4. **`train_0025` (Multi-Match Contact Disambiguation)**:
   - *Original*: `"gọi cho bạn Minh"` -> `contacts.search` returns 2 contacts (`c_05`, `c_08`). Calls `sys.ask_missing_info`.
   - *Converted SFT*: 13 messages, 6 assistant turns. Turn 5 calls `sys.ask_missing_info`.
   - *Verdict*: Correctly models disambiguation as an executable system action.
5. **`train_1696` (Label Defect & Hallucination Reinforcement)**:
   - *Original*: Label contains non-existent `chat_id="chat_6142"` returning `done: false`.
   - *Converted SFT*: `<think>` asserts `chat_6142` is valid and asserts task is complete.
   - *Verdict*: **Semantically harmful**. SFT actively trains the model to generate hallucinated IDs and ignore tool errors.
